  无水印下载 App（抖音 / B站 / 小红书 保存工具）
═══════════════════════════════════════════

【安装方法】
1. 把「build\wmsave.apk」传到手机（微信/QQ/数据线/网盘都行）
2. 在手机上点击该文件安装
3. 如果提示「未知来源/允许安装」→ 打开设置允许即可
   （不同手机位置不同：设置→安全→安装未知应用，允许"文件管理"或"微信"）

【使用方法】
1. 打开 抖音 / B站 / 小红书 App
2. 找到想保存的视频或图集 → 点「分享」→「复制链接」
3. 打开「无水印下载」App → 点「粘贴剪贴板」→ 点「解析」
4. 出现作品信息后选择：
   · 视频：下载无水印视频 / 保存为动图 GIF / 下载封面
   · 图集：一键下载全部图片
5. 界面会显示下载进度，完成后自动保存到系统相册：
   相册 → 「无水印下载」文件夹（视频在相册的"视频"分类里）
6. 下载过程中请保持 App 在前台，不要切走

【功能支持】
✅ 抖音视频去水印下载（直接保存到相册）
✅ B站视频去水印下载
✅ 小红书视频 / 图集去水印下载
✅ 视频转动图 GIF（最长 8 秒）
✅ 封面图下载
✅ 下载进度条显示

【常见问题】
· 解析失败提示"暂不支持该平台" → 目前只支持 抖音 / B站 / 小红书
· 小红书解析失败提示"缺少访问凭证" → 从小红书 App 重新复制分享链接
  （链接必须包含 xsec_token 参数）
· 相册里找不到 → 打开系统相册，在相册列表里找「无水印下载」文件夹；
  个别手机相册需要点右上角菜单 →「刷新」或等几秒
· Android 7-9 老系统 → 首次下载会询问"存储权限"，点允许
· 网络问题 → 手机和电脑一样，开了代理工具但没正常退出时可能断网

【重新构建】
工程目录：桌面\无水印保存\
重新打包：双击 build.bat（需要保持 tools 目录完整）
APK 输出：桌面\无水印保存\build\wmsave.apk
